# マルチモーダル経路計画シミュレーション（徒歩・バス・タクシー）

本リポジトリは、2026/11/28 日本経営システム学会発表大会用の検証実験を再現するためのコードです。

詳細なモデル・数式は [`abstract.md`](abstract.md) および [`ARCHITECTURE.md`](ARCHITECTURE.md) を参照してください。

## 概要

徒歩・バス・タクシーを組み合わせたマルチモーダル経路を、時間拡張型スーパーインポーズネットワーク上で最適化・評価します。

- **徒歩ネットワーク（ベース層）**: 徒歩ノード・徒歩エッジ
- **乗物ネットワーク（上位層）**: バス・タクシーノード・エッジを徒歩ノードと同一座標に重ねる
- **乗換**: 徒歩⇔乗物はダミーノード・ダミーエッジで接続。乗車側（徒歩→ダミー）のみコスト（時間依存、待ち時間等）、降車側（ダミー→徒歩）はコスト0
- **個人**: 歩行能力、歩行困難度閾値、歩行意欲（多目的最適化後のスコアリング用重み）など
- **オーダー**: 出発・到着ノード、到着時刻、到着重視度など
- **経路計画**: 個人ごとの制約に基づき多目的最適化で候補経路を生成し、スコアリングで選択

## 環境構築

- Python 3.9+
- 依存パッケージは `src/` のインポートを参照（または `requirements.txt` があれば使用）

```bash
pip install -r requirements.txt  # 存在する場合
```

## 再現手順

1. **マップ作成**: `config/map_config/` の設定と `data/` の地図データからネットワークを構築
2. **個人・オーダー生成**: `config/scenarios/` から属性・オーダーを生成
3. **制約適用**: 個人ごとの歩行困難度閾値に基づき使用不可エッジを除外
4. **多目的最適化**: パレート最適な経路候補を生成
5. **スコアリング・選択**: 歩行意欲・到着重視度等で候補を評価・選択
6. **実行・出力**: 結果は `simulation/SIMXXX.json` に保存

実行方法は `src/` 内の各モジュール（エントリーポイント）を参照してください。
