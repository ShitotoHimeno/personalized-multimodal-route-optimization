### ネットワーク構造（時間拡張ノードマップ）
徒歩用ノードを位置情報で結んだ**徒歩ネットワーク**（ベース層）の上に、
バス・タクシーの**乗り物ノード・エッジを重ねる**（スーパーインポーズ方式）。

- 乗り物ノードは**徒歩ノードと同座標**（co-located）に配置する
- 乗り物エッジは対応する**徒歩エッジ（歩行回廊）と並走**させる
- 徒歩と乗り物は**ダミーエッジ**で接続する。乗車側（徒歩→ダミー）は時間依存のコスト
  （バスは時刻表、タクシーは到着時間）、降車側（ダミー→徒歩）はコスト0
- 同座標のまま重ねるだけではバスの時刻表のような**時間依存**を扱えないため、
  ダミーエッジを挟んで乗車待ち時間を吸収する
- 全て有向グラフ。ダミーノードに入るエッジではコストがかかり、
  ダミーノードから出るエッジではコストなし

### エッジ
近くの同ノードを繋げる
位置情報を用いて距離を算出する
徒歩用ノード間では困難度も算出する（ほかのエッジでは０）
