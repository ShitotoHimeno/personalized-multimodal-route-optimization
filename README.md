# 1ノードマップ作成
## マップ情報
### ノード
徒歩用ノード（x,y,z）

タクシーノード

バスノード

ダミーノード


### エッジ
近くの同ノードを繋げる
位置情報を用いて距離を算出する
徒歩用ノード間では困難度も算出する（ほかのエッジでは０）
ダミーノードにつなげるダミーエッジについて
    今回はバスノードとタクシーノードに徒歩ノードから移動する際のもの
    時間依存で変更する。バスは定期的に移動するので時間表、タクシーはタクシーノードを使って現在地からのかかる時間がそのままダミーエッジの時間となる
    全てのダミーエッジは徒歩ノードとダミーエッジをつなげる
今回は全て有向グラフにし、ダミーノードに入るエッジではコストがかかりダミーノードから出てくるエッジではコストなしになる。


# 2個人情報群作成
## 個人情報
### 歩行能力
歩行ノードの走行スピード
疲労しないとする

###　歩行困難
エッジの困難度に閾値を設上回るエッジは走行しない→ノードマップから削除

###　歩行意欲
多目的最適化の後のスコアリングで用いる重みベクトル

## オーダー情報
### 出発・到着ノード
ここの置き方によって（つまりダミーノードにつながるノードが出発・到着ノードなら徒歩が要らない）

### 到着時間
到着時間の制約
なしもあり得る
これは経路計画の際に用いられる

### 到着重視度
到着時間の制約性
歩行意欲と合わせて1
