## ノードマップの設定（map_config）仕様

地図生成の設定は **`map_config.json`（本体）** で与える。本ファイルはその仕様を説明するマークダウンである。

### ネットワークの基本構造（時間拡張ノードマップ）

- **徒歩ネットワーク**（ベース層）: 徒歩用ノード（`x, y, z`）を位置情報で結ぶ。徒歩エッジは距離 `distance_m` と困難度 `difficulty` を持つ。
- **乗り物ネットワーク（重ねる層）**: バス・タクシーの乗り物ノードは**徒歩ノードと同座標**（co-located）に配置し、乗り物エッジは対応する徒歩エッジ（歩行回廊）と**並走**（スーパーインポーズ）させる。
- **ダミー（乗降）エッジ**: 乗り物ノードと**同座標の徒歩ノードのみ**を結ぶ。乗車側（徒歩→ダミー）は **時間依存のコスト**（バスは時刻表、タクシーは到着時間）、降車側（ダミー→徒歩）は **コスト 0** とする。同座標で直接重ねるだけではバスの時刻表のような**時間依存**を扱えないため、このダミーエッジを挟んで乗車待ち時間を吸収する。
- 全て **有向グラフ**。ダミーノードに入るエッジ（乗車）ではコストがかかり、ダミーノードから出るエッジではコスト 0。

```
 徒歩ノード ────(徒歩エッジ)────> 徒歩ノード
    │                               │
 [乗車ダミーエッジ:時間依存]   [乗車ダミーエッジ:時間依存]
    │                               │
 乗り物ノード ──(乗り物エッジ:並走)──> 乗り物ノード
```

### 記法について

- `map_id`: 環境を固定するための識別子。同じ `map_id` と `random_seed` から同一のマップを再現できる。
- `random_seed`: ノード配置・エッジ生成・困難度算出に用いる乱数シード。
- `coordinate`: 座標系・単位・各軸の上限（`bounds`）。
- `nodes`: ノード種別ごとの生成数。`taxi.count` / `bus.count` は**乗り物ノードを重ねる徒歩ノードの数**（その徒歩ノード位置に co-located で配置される）。
- `edges`: エッジ生成規則（接続半径、距離指標、困難度算出、ダミーエッジの向きとコスト、乗り物エッジの並走規則）。
- `time_dependency`: 時間依存ノード（ダミーエッジ・運行エッジ）の定義。**タクシーへのダミーエッジとバスへのダミーエッジは時間依存の関数が異なる**ことを明示する。
- `time`: 時間拡張ノードマップの時間軸設定。

### フィールド一覧

| フィールド | 説明 |
| --- | --- |
| `map_id` | マップ識別子 |
| `random_seed` | 乱数シード |
| `coordinate.type` | 座標系（`local_cartesian`） |
| `coordinate.unit` | 長さの単位（`meter`） |
| `coordinate.bounds.{x,y,z}` | 各軸の `min` / `max`（座標情報の上限） |
| `nodes.walk.count` | 徒歩用ノード数 |
| `nodes.taxi.count` | タクシーノード数（co-located にする徒歩ノード数） |
| `nodes.bus.count` | バスノード数（co-located にする徒歩ノード数） |
| `edges.directed` | 有向グラフかどうか（`true`） |
| `edges.walk.connect_radius` | 近傍同種ノードを繋げる距離閾値 |
| `edges.walk.isolation_fallback` | 徒歩ノードが孤立しないよう歩行ネットワークを連結にするか（成分間の最短ペアを追加接続, `true`） |
| `edges.walk.distance_metric` | 距離算出法（`euclidean`） |
| `edges.walk.difficulty.calc` | 徒歩エッジで困難度を算出するか |
| `edges.walk.difficulty.{min,max}` | 困難度の範囲 |
| `edges.dummy.connect` | ダミーエッジが繋ぐノード種別（`walk` と `dummy`） |
| `edges.dummy.co_located_only` | ダミーエッジを同座標の徒歩ノードとのみ接続するか（`true`） |
| `edges.dummy.enter_has_cost` | ダミーノードに入るエッジにコストを課すか（`true`） |
| `edges.dummy.exit_has_cost` | ダミーノードから出るエッジにコストを課すか（`false`） |
| `edges.transit.superpose_on` | 乗り物エッジが並走する層（`walk`） |
| `edges.transit.bus_route` | バス路線の作り方（`contiguous_walk_path`: 歩行エッジを辿る連続経路） |
| `edges.transit.taxi_network` | タクシーの移動ネットワーク（`superposed_subgraph`: 歩行エッジに並走） |
| `time_dependency.taxi.type` | 時間依存の種別（`continuous`） |
| `time_dependency.taxi.function` | タクシーの時間依存関数（`taxi_arrival_time`） |
| `time_dependency.bus.type` | 時間依存の種別（`timetable`） |
| `time_dependency.bus.function` | バスの時間依存関数（`bus_timetable`） |
| `time.horizon_sec` | 時間軸の上限（秒） |
| `time.step_sec` | 時間の刻み幅（秒） |

### ノード種別の役割

| ノード種別 | ID | 役割 |
| --- | --- | --- |
| 徒歩用ノード | `walk:{i}` | 物理的な位置（x, y, z）。出発・到着地点 |
| タクシーノード | `taxi:{i}` | タクシー乗降点。対応する徒歩ノード `host` と同座標 |
| バスノード | `bus:{i}` | バス停。対応する徒歩ノード `host` と同座標 |
| ダミーノード | `dummy:{mode}:{i}` | 乗降地点。徒歩と乗り物を接続し、時間依存の待ち時間を持つ |

### エッジの役割

| エッジ種別 | 接続 | コスト |
| --- | --- | --- |
| 徒歩 `walk` | 徒歩ノード間（距離 `connect_radius` 以内） | 時間 = 距離/歩行速度、負荷 = 距離×困難度 |
| 乗車 `board` | 徒歩ノード → ダミーノード（同座標） | 時間依存（バス: `bus_timetable`, タクシー: `taxi_arrival_time`） |
| 乗込 `enter` | ダミーノード → 乗り物ノード | 0 |
| 降車 `exit` | 乗り物ノード → ダミーノード | 0 |
| 降車 `alight` | ダミーノード → 徒歩ノード（同座標） | 0 |
| 運行 `transit` | 乗り物ノード間（歩行エッジと並走） | タクシー: 走行時間, バス: 時刻表 + 走行時間 |

### バス路線の作り方

- `nodes.bus.count` 個の徒歩ノードを、「徒歩エッジ（歩行回廊）を連続して辿る」**経路**として選ぶ（隣接間は必ず徒歩エッジで接続される。`isolation_fallback` で追加した接続も徒歩エッジとして利用可能）。
- その経路の徒歩ノード位置にバスノードを co-located で置き、隣接バスノード間を運行エッジ（`bus_timetable`）で結ぶ（往復）。

### タクシーネットワークの作り方

- `nodes.taxi.count` 個の徒歩ノードをランダムに選び、その位置にタクシーノードを co-located で置く。
- 対応する徒歩ノード間に徒歩エッジが存在する（= 歩行回廊がある）ペア同士を運行エッジ（`taxi_ride`）で結ぶ（徒歩エッジと並走）。

### 時間依存の違い

- **タクシーへのダミーエッジ**: 現在地（同座標の徒歩ノード）からタクシーが到着するまでの時間（待ち時間）がそのままダミーエッジの時間となる**連続的**な関数（`taxi_arrival_time`）。走行は運行エッジ（`taxi_ride`）で評価する。
- **バスへのダミーエッジ**: 定期的に運行するため時刻表に従い、離散的な時刻ノードとして現れる**時刻表ベース**の関数（`bus_timetable`）。
